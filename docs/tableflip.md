# (╯°□°）╯︵ ┻━┻ Table Flip (tableflip)

Play a 4-step table flip animation.

---

## Commands

| Command | Description |
|---------|-------------|
| `$flip` | Play a 4-step table flip animation |

> **Cooldown:** 60 seconds per user per channel.

---

## Examples

**Flip a table:**
```
<User> $flip
<Glitchy> (ノ ゜Д゜)ノ ︵ ┻━┻
<Glitchy> (ノಠ益ಠ)ノ彡┻━┻
<Glitchy> ┻━┻ ︵ヽ(`Д´)ﾉ︵ ┻━┻
<Glitchy> ┬─┬ノ( º _ ºノ) ...ok I'm done.
```
