# 🤦 Facepalm (facepalm)

Auto-trigger: when someone does `/me facepalms` or `/me facepalmed`, the bot replies with a random facepalm reaction.

---

## Setup

**No config needed.** Just drop the script in place and it works.

**1. Place the script:**
```
~/.sopel/scripts/facepalm.py
```

---

## Triggers

| Trigger | Description |
|---------|-------------|
| `/me facepalms` | Triggers a bot reaction |
| `/me facepalmed` | Also triggers a bot reaction |

> **Channel cooldown:** 15 seconds.

---

## Examples

**Facepalm in action:**
```
* User facepalms
<Glitchy> User, that was so bad even Picard facepalmed. 🤦
```

**Another response:**
```
* User facepalmed
<Glitchy> User's facepalm echoed across the universe. 🌌🤦
```
